## DHCP Snooping

DHCP Snooping is a Layer 2 security feature that protects a network against rogue DHCP servers by allowing only authorized DHCP servers to participate in the DHCP process.

When a client connects to a network, it requires basic network configuration such as an IP address, subnet mask, default gateway, and DNS server. To obtain this information, the client starts the DHCP process by broadcasting a DHCP Discover message.

The complete DHCP process is known as DORA:

- Discover
- Offer
- Request
- Acknowledge

The problem is that DHCP does not authenticate DHCP servers. Any device connected to the network can respond to a DHCP Discover message with a DHCP Offer. If a rogue DHCP server responds before the legitimate one, the client may accept malicious network configuration.

DHCP Snooping prevents this attack by introducing two types of switch ports:

### Trusted Ports

Trusted ports are interfaces connected to legitimate network infrastructure, such as:

- The authorized DHCP server.
- Routers.
- Distribution or core switches.
- Other trusted network devices.

These ports are allowed to send DHCP server messages such as DHCP Offer and DHCP Acknowledge.

### Untrusted Ports

All switch ports are considered untrusted by default.

These ports are typically connected to endpoints such as:

- PCs.
- IP phones.
- Printers.
- Access points.
- User devices.

Devices connected to untrusted ports are allowed to send DHCP client messages (Discover and Request), but they are not allowed to send DHCP server messages.

If a rogue DHCP server connected to an untrusted port attempts to participate in the DORA process by sending DHCP Offer or DHCP Acknowledge messages, the switch immediately drops those packets.

Normal traffic generated by devices connected to untrusted ports is not affected. DHCP Snooping only filters DHCP server messages arriving on untrusted interfaces.

## DHCP Snooping Binding Table

As DHCP clients successfully obtain their network configuration, the switch builds a DHCP Snooping Binding Table.

This table stores information such as:

- Client MAC address.
- Assigned IP address.
- VLAN.
- Switch interface.
- Lease time.

The binding table allows the switch to verify which IP address legitimately belongs to each MAC address.

This information is later used by other Layer 2 security features, such as Dynamic ARP Inspection (DAI), to validate ARP packets and prevent ARP Spoofing attacks.

## Option 82

DHCP Snooping can also insert DHCP Option 82, also known as the Relay Agent Information Option.

Option 82 adds information about the switch port where the DHCP request originated. This allows the DHCP server to identify the client's location within the network and apply different IP address assignment policies if necessary.

Although Option 82 is commonly used in enterprise environments, its configuration depends on the network design and is not required for basic DHCP Snooping operation.
