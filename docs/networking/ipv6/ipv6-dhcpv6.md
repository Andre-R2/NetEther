# DHCPv6

## Overview

In DHCPv4, it's common for the server to handle practically everything: assigning the IP, subnet mask, gateway, DNS servers, and so on. The client would simply ask, and the server would respond with the full configuration.

In IPv6, the router actively participates in the configuration process. The router can announce the network prefix, the default gateway, the MTU, and whether a DHCPv6 server should be consulted at all.

In other words, the DHCPv6 server is no longer necessarily responsible for everything.

## The two modes

### 1. Stateless DHCPv6

The router indicates:

```text
A = 1
O = 1
```

The IPv6 address is generated by the device itself through SLAAC — the server only provides supplementary information, such as DNS servers. Just complementary data, not the address itself.

### 2. Stateful DHCPv6

The router indicates:

```text
A = 0
M = 1
```

This means the device should not generate its address through SLAAC. Instead, it requests an address from the DHCPv6 server, and the server responds with the full configuration. This is the mode that most closely resembles traditional DHCPv4.

## What the flags mean

The router advertises three flags that control this behavior:

A (Autonomous) — indicates whether the client is allowed to build its own address using SLAAC.

- `A = 1` → Yes
- `A = 0` → No

M (Managed) — `M = 1` means the client must use DHCPv6 to obtain its address.

O (Other) — `O = 1` means the client uses DHCPv6 to obtain other parameters (DNS, search domain, NTP, etc.), regardless of whether the address itself came from SLAAC.

## Flag combinations at a glance

Putting all three flags together makes the three possible modes easier to tell apart:

| Mode | A | M | O | What happens |
|---|---|---|---|---|
| SLAAC only | 1 | 0 | 0 | Client generates its own address via SLAAC. No DHCPv6 involved at all. |
| Stateless DHCPv6 | 1 | 0 | 1 | Client generates its own address via SLAAC, but gets extra info (DNS, etc.) from DHCPv6. |
| Stateful DHCPv6 | 0 | 1 | 1 | Client doesn't self-generate an address — DHCPv6 assigns the full configuration, closest to how DHCPv4 works. |
